How to read this page

  • Zone cards: the latest reading of each room or area. Colours show comfort: green is good, orange is borderline, red is poor. A red border means the zone has a recent security alert.
  • Power chart: how much electricity each zone uses, updated with every new reading.
  • Alerts and agent: the newest security alerts and what the AI agent decided about them.

AI security agent

When a detector raises an alert, the AI agent investigates it like a security analyst would: it checks the data, decides whether the alert is a real attack, and takes safe corrective action.

1. AlertA detector flags suspicious readings in a zone.
2. InvestigateThe agent reads recent sensor, energy, weather and carbon data and re-runs the detectors.
3. DiagnoseReal attack or false alarm? It explains the cause and the energy impact.
4. Safety checkFixed rules approve or block every proposed action. The AI cannot skip this.
5. Act & recordApproved actions run on the simulated building; everything is saved.

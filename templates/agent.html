How decisions are made
  1. An alert arrives → the agent gathers sensor, energy, weather/carbon data and re-runs the detectors (tools).
  2. It diagnoses the cause and explains the energy and operational impact.
  3. It proposes actions; a deterministic safety validator approves or rejects each one.
  4. Only approved actions run — on the simulator — and everything is recorded.

Provider offline = deterministic rule-based playbook (no LLM); anthropic = Claude. If the LLM fails, the record shows the fallback.
